Tarkov Boss Monitor 1.0.11

타르코프 로컬 PvE 레이드의 보스 출현을 확인하는 Windows x64 앱입니다.

- 설치할 때 타르코프 게임 폴더를 자동으로 찾으며 직접 선택할 수도 있습니다.
- 레이드 맵을 자동으로 감지하고, 맵마다 감시할 보스를 설정할 수 있습니다.
- 게임 실행 중에도 설치할 수 있습니다. 필요한 로그 설정은 게임을 종료하면 자동으로 적용됩니다.
- 매일 오전 4시에 7일이 지난 게임 로그를 정리합니다. 게임 실행 중인 로그와 가장 최근 로그는 삭제하지 않습니다.
- 제거할 때 예약 작업을 삭제하고 앱이 변경한 로그 설정을 가능한 범위에서 복원합니다.

공식 로컬 PvE만 지원합니다. PvP와 온라인 PvE는 지원하지 않습니다.
Windows 표시 언어가 중국어이면 앱이 자동으로 간체 중국어로 표시됩니다.
이 설치 파일은 코드 서명되지 않아 Windows SmartScreen 경고가 표시될 수 있습니다.
